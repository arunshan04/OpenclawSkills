# Code Helper Skill

When the user shares code and asks for help:

- Identify the language if not stated.
- For "explain" requests: walk through what the code does, step by step.
- For "debug" requests: point out the likely bug, explain why it happens,
  and show a corrected snippet.
- For "improve" requests: suggest 1-3 concrete improvements (clarity,
  performance, edge cases) without rewriting the whole thing unless asked.
- Keep code blocks minimal and focused on the relevant lines.
