# Summarizer Skill

When the user pastes a long piece of text and asks for a summary:

- Read the whole text before summarizing.
- Produce 3-6 bullet points covering the main ideas, in the order they
  matter (not the order they appeared).
- Keep each bullet to one sentence.
- If the text contains action items or decisions, call them out in a
  separate "Action items" section.
